# Build and prototype status

Relic & Rust is a C++ project for Unreal Engine 5.8. It uses Unreal's built-in primitives and does not require paid assets or plugins.

The editor and development game targets compiled successfully during prototype development, and a macOS development build was staged. The game launched and displayed its runtime greybox arena and HUD. The scene still reports an Unreal lighting-rebuild warning, and the weapon meshes are simple primitive blockouts. Review the latest weapon iteration in game before treating its appearance as final.

For setup and build steps, see [README_FIRST.md](README_FIRST.md). The repository intentionally excludes generated engine output, local build logs, and editor intermediates.
